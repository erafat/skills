# BibTeX Bibliography Template

This template generates a separate .bib file for use with LaTeX or reference managers.

## File Naming

```
{manuscript_name}.bib
```

Example: If manuscript is `paper.md`, create `paper.bib`

## BibTeX Entry Types

### Journal Article (@article)

```bibtex
@article{smith2024effects,
  author    = {Smith, John A. and Jones, Brian C. and Williams, Diana E.},
  title     = {The Effects of Climate Change on Coral Reef Ecosystems},
  journal   = {Nature Climate Change},
  year      = {2024},
  volume    = {14},
  number    = {3},
  pages     = {234--245},
  doi       = {10.1038/s41558-024-01234-5},
  pmid      = {12345678},
  abstract  = {Abstract text here...}
}
```

### Preprint (@unpublished or @misc)

bioRxiv/medRxiv preprints:

```bibtex
@unpublished{smith2024novel,
  author    = {Smith, John A. and Jones, Brian C.},
  title     = {Novel Therapeutic Targets in {Alzheimer's} Disease},
  year      = {2024},
  note      = {bioRxiv preprint},
  doi       = {10.1101/2024.01.15.123456},
  url       = {https://doi.org/10.1101/2024.01.15.123456}
}
```

Alternative format (some styles prefer @misc):

```bibtex
@misc{smith2024novel,
  author       = {Smith, John A. and Jones, Brian C.},
  title        = {Novel Therapeutic Targets in {Alzheimer's} Disease},
  year         = {2024},
  howpublished = {bioRxiv},
  doi          = {10.1101/2024.01.15.123456},
  note         = {Preprint}
}
```

### Review Article

Use @article with optional keywords field:

```bibtex
@article{smith2024review,
  author    = {Smith, John A.},
  title     = {A Comprehensive Review of Cancer Immunotherapy},
  journal   = {Nature Reviews Cancer},
  year      = {2024},
  volume    = {24},
  number    = {5},
  pages     = {301--320},
  doi       = {10.1038/s41568-024-00678-x},
  keywords  = {review}
}
```

## Citation Key Generation

Format: `{firstauthor_surname}{year}{first_significant_word}`

Rules:
1. First author's surname (lowercase)
2. Publication year
3. First significant word from title (skip articles: a, an, the)
4. If duplicate, append a, b, c...

Examples:
- `smith2024effects`
- `jones2023marine`
- `smith2024effectsa` (if duplicate exists)

## Required Fields by Entry Type

### @article (Required)
- author
- title
- journal
- year

### @article (Recommended)
- volume
- number (issue)
- pages
- doi

### @unpublished (Required)
- author
- title
- year
- note

## Special Characters

Protect special characters and proper nouns with braces:

```bibtex
title = {The Role of {COVID-19} in {Alzheimer's} Disease Progression}
title = {Gene Expression in {E. coli} Under Stress}
title = {{DNA} Methylation Patterns in Cancer}
```

## Author Formatting

```bibtex
% Single author
author = {Smith, John A.}

% Two authors
author = {Smith, John A. and Jones, Brian C.}

% Multiple authors
author = {Smith, John A. and Jones, Brian C. and Williams, Diana E. and Brown, Frank G.}

% Corporate author
author = {{World Health Organization}}

% Author with suffix
author = {Smith, Jr., John A.}
```

## Integration with Manuscript

### For Markdown with Pandoc

In the manuscript, use citation keys:

```markdown
Studies show significant effects [@smith2024effects].
Multiple sources confirm this [@jones2023marine; @smith2024effects].
```

Compile with:
```bash
pandoc manuscript.md --bibliography=manuscript.bib --citeproc -o output.pdf
```

### For LaTeX

In the manuscript:
```latex
\bibliography{manuscript}
\bibliographystyle{plain}  % or apalike, ieeetr, etc.
```

Use `\cite{smith2024effects}` for citations.

## Metadata Fields

Optional fields to include when available:

```bibtex
@article{key,
  % ... required fields ...
  abstract  = {Full abstract text},
  keywords  = {keyword1, keyword2, keyword3},
  pmid      = {PubMed ID},
  pmcid     = {PMC ID},
  issn      = {Journal ISSN},
  url       = {Article URL},
  note      = {Additional notes}
}
```
