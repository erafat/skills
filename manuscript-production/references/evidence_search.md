# Evidence Search Workflow

## Purpose

Prevent late reference hunting by making source discovery the first production task after the brief.

## Tool Order

Use the best available source-discovery tools early:

- OpenEvidence MCP, when configured, for focused clinical questions and candidate evidence leads.
- PubMed or journal sites for bibliographic verification.
- Guidelines and society statements for practice claims.
- Full text PDFs for exact claim support.
- Zotero or local libraries for citation hygiene.

## OpenEvidence MCP Use

If available, use it to ask narrow questions such as:

- What is the best evidence connecting [condition/exposure] to [outcome]?
- Are there randomized trials, systematic reviews, or guidelines on [intervention]?
- What evidence contradicts or limits the proposed claim?
- Which outcomes are directly shown versus inferred?

Record each useful lead with:

- question asked
- source or article returned
- claim it might support
- whether full text was verified
- caution or limitation

Do not treat AI-generated synthesis as a citation. Treat it as a path to sources that still need verification.

## Minimum Stop Rule

Before drafting, the source packet should contain enough verified sources to support the manuscript spine:

- background/framing
- main evidence
- mechanism or rationale
- limitation/counterevidence
- guideline or practice context, if relevant
