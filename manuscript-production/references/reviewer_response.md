# Reviewer Response Workflow

## Process

1. Extract reviewer comments into discrete actionable items.
2. Group global concerns separately from line edits.
3. Map each item to manuscript location.
4. Decide response status: addressed, partially addressed, disagree with rationale, or requires user judgment.
5. Draft response-letter language only after confirming manuscript changes exist.

## Response Style

- Be respectful and specific.
- Name the change made.
- Avoid claiming a revision was made if only the response letter changed.
- For disagreement, explain the rationale and acknowledge the concern.
- For uncertain evidence, state what was clarified rather than overselling.
