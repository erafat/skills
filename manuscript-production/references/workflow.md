# Manuscript Production Workflow

## Minimum Viable Source Packet

Before drafting, collect enough sources to support the paper's spine:

- 2-5 background or framing sources
- 5-10 core evidence sources
- 1-3 guideline or methods sources if relevant
- 2-5 limitation, counterpoint, or uncertainty sources

The goal is not exhaustive searching before prose. The goal is to prevent writing claims whose evidence base is unknown.

## Stage Outputs

Brief: one-sentence thesis, target audience, target venue, success measure, forbidden overclaims.

Source packet: source list grouped by manuscript role, not just bibliography order.

Evidence matrix: study type, population, outcome, key finding, limitations, and which claim each source supports.

Claim ledger: every major claim has a support level and allowed wording.

Outline: each section has a job, claims, sources, and risks.

Draft: preserves the user's voice and follows the evidence-backed outline.

Verify: audits reviewer alignment, claim strength, references, word count, and readiness.

Ship: produces coauthor or submission packet with explicit remaining risks.

For clinical source discovery, see `evidence_search.md`.
