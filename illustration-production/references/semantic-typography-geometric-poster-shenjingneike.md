# Example: 神经内科

Use with `Semantic Typography Concept Poster` -> `Geometric Typographic Concept Poster`.

## Filled Prompt

请基于核心文字【神经内科】创作一张高完成度的「现代平面几何字体概念海报 / Geometric Typographic Concept Poster」。

文字语言：【中文】

补充语境：【医学、神经系统、临床专科、清晰诊断、网络化信息传导】

情绪倾向：【冷静、专业、理性、精密、可信、清亮】

禁用元素：【写实大脑、医生肖像、医院走廊、药品包装、恐怖化神经影像、过度科技蓝光、脏旧纹理】

请真正理解“神经内科”的语义：它不是单纯的大脑插画，而是关于神经系统、信号传导、临床观察、诊断路径、结构秩序与人体内部网络的医学专科。画面应把“神经内科”四个字设计成第一视觉主体，让文字本身像一个清晰的神经网络和诊断系统：笔画之间可以被几何节点、细线通路、透明模块、网格坐标、切片框和少量数据感标签连接，但必须保持中文可读性。

构图建议：使用现代平面几何排版，核心文字大幅占据画面中部或偏左主视觉区；“神经”可通过节点、分叉线、细密但克制的路径表达神经信号，“内科”可通过稳定矩形网格、诊断框、分层透明色块表达临床系统和专业秩序。可以让少量线段穿过文字或连接笔画端点，形成“信息传导”的结构隐喻；可加入一个极简圆环或半透明扫描窗口作为视觉重心，但不要画写实大脑。

配色方向：以 warm white / clinical white 为背景，搭配 deep navy、silver blue、aqua cyan、少量 coral red 或 vivid yellow 作为诊断标记点。整体清爽、理性、明亮、有医学可信感，不要暗黑、沉重或过度科幻。

字体与排版：中文使用有力量的现代无衬线标题字或几何黑体风格，粗细稳定，边缘清晰，允许局部切片、错位、透明遮挡和网格嵌套，但不能损害“神经内科”的识别。可加入极短小字副标题，例如：“信号、结构与诊断”或 “Signals / Structure / Diagnosis”，小字必须克制，不能抢主标题。

图形系统：使用圆点节点、细线连接、矩形诊断框、透明叠层、模块化网格、少量箭头或路径线。所有图形都应解释“神经内科”的语义，而不是装饰背景。画面应像一张现代医学视觉识别海报：clean flat design、geometric composition、typographic poster、experimental typography、crisp vector-like precision、contemporary clinical visual identity。

最终成图应让人感觉：“神经内科”被设计成了一个视觉符号；文字、线网、节点、诊断框和留白共同组成一个清晰的医学语义系统；专业但不冰冷，理性但不空洞，现代、有传播力、可作为医学讲座封面或专科概念海报。
